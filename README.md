# Data Portfolio: Claudine Uwanyirigira

Three sample projects that show how I turn messy data into clear dashboards and reports. **All data is fictional**, generated by `scripts/generate_data.py`. No employer or client data is used.

| Sample | Problem it solves | Open |
|---|---|---|
| Retail sales dashboard | Compare revenue, margin and category mix across branches in one interactive view | `dashboard.html` |
| Survey data cleaning | Turn a messy survey export into analysis-ready data, with a log of every change | `cleaning.html` |
| 2025 sales report | Explain where revenue comes from and where to focus next, in plain language | `report.html` |

## Run it yourself

```
python scripts/generate_data.py   # creates the fictional CSVs in data/
python scripts/clean_survey.py    # cleans the survey, writes data/survey_clean.csv and cleaning_log.json
python scripts/build_site.py      # rebuilds the HTML pages
```

Requires Python 3 with `pandas` and `numpy`.

## Publish free on GitHub Pages

1. Create a new public GitHub repository (for example `data-portfolio`) and upload everything in this folder.
2. In the repository, open **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. After a minute your portfolio is live at `https://<your-username>.github.io/data-portfolio/`.
